# Lab 02: AI in Everyday Challenges (Group Activity)

## Laboratory Session
Lab 02, AI in Everyday Challenges (group activity) (PUSL 3205)

## Objective
Use an LLM as a product-development partner to design a product concept for an everyday
challenge faced by students, per [Lab sheet 2](resources/Lab%20sheet%202.pdf).

## Tasks and Implementation
- Challenge card: **Group 1 — The Forgetful Student** (students forgetting things like ID cards,
  chargers, and USB drives before lectures or labs)
- [group-activity/activity-outcomes.md](group-activity/activity-outcomes.md): the product concept,
  target user, and key features
- [group-activity/discussion-summary.md](group-activity/discussion-summary.md): how the group
  arrived at the idea and what we'd improve with more time
- Our product: **PackWise**, a packing companion that reads the student's timetable, builds a
  daily packing list from it, and reminds them before they leave
- [group-activity/Packwise.pptx](group-activity/Packwise.pptx): presentation slides
- [group-activity/packwise_app_flow.png](group-activity/packwise_app_flow.png): app flow diagram
- [group-activity/PackWise App.html](group-activity/PackWise%20App.html): an interactive HTML
  mock-up of the app (open in a browser)

## Observations
- Having the LLM as a brainstorming partner helped us move past the first, obvious idea (a plain
  checklist app) to something with more going on — the bag-scan and "what you forget most"
  features both came out of pushing the idea further with it.
- The mock-up is a clickable HTML prototype, not a working app — the bag-scan screen, for
  example, doesn't actually run image recognition, it just shows what that screen would look like.

## Learning Outcomes
- Practiced using an LLM as a product-development partner rather than just a question-answering
  tool — for naming, features, and copywriting.
- Learned to turn a short, vague problem statement into a concrete product concept with a named
  target user and specific features.
- Experienced building a quick interactive mock-up good enough for a short pitch, rather than a
  fully working app.
