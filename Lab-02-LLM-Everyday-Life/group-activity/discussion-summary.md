# Discussion Summary

## Problem discussion

We got "The Forgetful Student" card from the lab sheet. Everyone in the group had a story about
forgetting a charger, ID card, or USB drive before a lecture or lab, so the problem felt very real
and easy to relate to straight away.

## Ideas considered

The first idea was just a simple packing checklist app, but that felt too close to a normal to-do
list. With the LLM's help we pushed past that and added the idea of scanning the actual bag with a
phone camera, plus reminders tied to the student's own timetable instead of a manual list.

## Decisions

We went with PackWise because it ties the packing list directly to the student's real timetable
instead of making them set reminders by hand. The bag-scan and "what you forget most" features
were added because they make the app feel smart rather than just a glorified checklist.

## What we'd improve

With more time, we'd actually build the photo-recognition part instead of a mock-up, and let the
app learn each student's habits over time instead of using the same fixed reminders for everyone.
